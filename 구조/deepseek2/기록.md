## llama.cpp 의 식 (b12224 — src/models/deepseek2.cpp · src/llama-graph.cpp 의 build_moe_ffn · build_attn_mha)

층 l(입력 x):

1. h = RMSNorm(x; `attn_norm`).
2. q: LoRA 가 있으면 q = `attn_q_b` · RMSNorm(`attn_q_a` · h; `attn_q_a_norm`), 없으면 q = `attn_q` · h. 헤드마다 [nope | rope].
3. kv = `attn_kv_a_mqa` · h → c = kv[0, 512), k_pe = kv[512, 576). c′ = RMSNorm(c; `attn_kv_a_norm`).
4. RoPE 는 NORM(이웃 짝 (2i, 2i + 1), θ_i = θ^(−2i/64)) — q 의 rope 부분과 k_pe(헤드 하나 — 모든 헤드가 같이 쓴다)에.
5. 흡수(weight absorption — llama.cpp 의 `is_mla`, 파일에 `attn_k_b` · `attn_v_b` 가 있다): 헤드 h 마다 q_abs,h = `attn_k_b`[h] · q_nope,h
   (512 × nope 행렬), Q_h = [q_abs,h | q_pe,h](576), K = [c′ | k_pe](576 — KV 헤드 하나), V = c′(512).
6. 어텐션(MQA — 질의 헤드가 모두 KV 헤드 하나를 본다): 점수 스케일 = 1/√(`key_length_mla`)(YaRN 이 없으면 mscale = 1 — GLM 1/16 ·
   Kanana-2 1/√192), 인과 마스크, softmax, × V → o_h(512).
7. o′_h = `attn_v_b`[h] · o_h(v × 512 행렬), 출력 = `attn_output` · [o′_0 | … | o′_(H−1)], x ← x + 출력.
8. h₂ = RMSNorm(x; `ffn_norm`). 층 < `leading_dense_block_count` 면 SwiGLU(`ffn_gate` · `ffn_up` · `ffn_down`), 아니면 MoE:
   l = `ffn_gate_inp` · h₂, p = σ(l), 고르는 점수 s = p + `exp_probs_b`(가중치에는 쓰지 않는다), 상위 k(s), w_r = p(e_r),
   w ← w / max(Σw, 6.103515625e-5)(`expert_weights_norm`), w ← w × `expert_weights_scale`, 출력 = Σ_r w_r · 전문가 e_r 의 SwiGLU
   + 공유 전문가의 SwiGLU(`ffn_*_shexp` — 게이트 없이 더한다), x ← x + 출력.
9. 끝: RMSNorm(x; `output_norm`), 로짓 = `output` · x.

`expert_group_count` 가 1 보다 크면 그룹 고르기가 더 있다(두 모델은 1). MTP 층(`nextn_predict_layers`)은 본 계산에 쓰지 않는다(두 파일에는 없다).

## 고른 것

- **흡수 방식의 MLA**: KV 캐시가 위치 · 층마다 원소 576 개(키) — 흡수하지 않으면 헤드마다 키 · 값이 따로라 GLM 은 20 × (256 + 256) =
  10,240 개(18 배)다. 문맥 32,768 에서 16비트 형식의 KV 가 GLM 47 층에 1.8 GB(값 캐시를 따로 두는 첫 버전은 3.4 GB) 대 31.5 GB.
  llama.cpp 도 이 방식이다.
- **값은 키의 앞 512 원소**: V = c′ 라 16비트 형식(8비트 자리 둘)의 값 블록 16 개는 키 블록 0 … 15 와 같은 정수 · 지수다. 첫 버전은
  Gemma 4 의 전체 층(v₀ = k₀)처럼 값 캐시를 따로 둔다(텐서 코어 행렬곱의 배치가 [차원][키]) — 메모리를 줄이는 것은 뒤에.
- **RoPE 는 NORM 짝 그대로**: llama 처럼 가중치의 줄을 옮기지 않고, 새 커널이 이웃 짝을 돌린다. 식은 계약 4.2 의 FMA 식에서 짝만 다르다.
- **헤드마다의 행렬곱**(`attn_k_b` · `attn_v_b`)은 1 절의 정수 블록 계약 — 헤드마다 다른 가중치. Q5_0(Kanana-2 의 `attn_k_b`)은 Q8_0 와
  같은 식(q − 16 ∈ [−16, 15], 블록 스케일 d)이라 불러올 때 Q8_0 로 바꾼다(값이 바뀌지 않는다).
- **라우팅**: σ 는 계약 4.9 의 식, s = p + b 는 fp32 덧셈 하나, 상위 k 는 4.11 의 3 을 s 로, 정규화는 4.11 의 4, 배율은 fp32 곱 하나, 전문가의
  합은 4.11 의 6, 공유 전문가는 fp32 덧셈 하나(4.11 의 7 은 σ 게이트의 FMA).
- **처음에는 좁게**: 정밀 모드만 · CUDA 만. 생성 그래프 · 표 스텝 · 추측 디코딩 · 슬롯 사이 복사 · 프롬프트 캐시 · 층 나누기 · 8비트 KV ·
  빠른 모드는 뒤의 단계에서.
