# 0.11.0 — 성능 큰 폭 개선 · 모델 넓히기 1단계 · 빠른 모드의 기본을 8비트 KV + 빠른 어텐션으로 (계획 2026-10-22, 고침 같은 날 · 10-23)

**버전 — 계획 때 이름은 1.0.0 이었고 0.11.0 으로 낸다.** 사용자 2026-10-23: "기존 버전이랑 호환이 안되는거도 아니고 별다른 큰변화도
없으면 1.0.0을 왜 올리지?", "이번작업 0.11.0으로 내고 0.12.0에서 모델확장지원진행해". 계획 때 '기본 설정의 출력 비트가 바뀌므로 MAJOR'
라고 적은 것은 [버전 규칙](버전규칙.md)을 잘못 읽은 것이었다 — 규칙의 출력 비트 호환은 같은 계산 방식(KV 캐시 8비트 · 빠른 어텐션 설정
포함)끼리라 기본값을 바꾸는 것은 호환을 깨지 않는다. 이 판의 바뀜(비트가 같은 더 빠른 커널 · 새 모양 · 새 형식 · 새 계산 방식 · 기본값)은
모두 MINOR 다. 단계 이름 1-0 ~ 1-7 과 코드 주석의 '1.0.0 1-x' 는 이 문서의 단계를 가리킨다. 1-6b(목록 넓히기)는 모델 확장과 함께 0.12.0
으로 옮겼다(아래 1-5 결과).

사용자 2026-10-22: "추천대로 진행하되 메이저버전을 올리려면 이번작업에 성능쪽개선을 큰폭으로 해서 이전과의 차이점을 보여줘야할것
같아". 0.10.2 뒤의 성능 추천 다섯(빠른 모드의 기본 · 프롬프트 행렬곱 효율 · 추측 검증 행 16 · 생성 스텝의 바닥 거리 · Qwen3 의 빠른
어텐션)을 한 판으로 묶고, 0.10.2 와의 차이를 같은 측정 묶음으로 보여 준다.

고침(사용자, 같은 날 — 1-0 과 초안 모델 측정 뒤): "초안 모델은 빼고, 1.0.0에 모델 넓히기 1단계(질의 폭 분리 · 이미 되는 모양 목록 추가 ·
형식 하나)를 넣어 계획을 고치고 진행해". 추측 검증 행 16 과 초안 모델은 측정으로 이득이 없어 뺐다(아래 '뺀 것').

빌드(b11719 · b11768 · b11796). 출처: [2c단계](2c단계.md) · [긴문맥](긴문맥.md) ③c · [빠른어텐션](빠른어텐션.md) F2-3.
