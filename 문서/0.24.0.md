**검증 도구를 고친 것**(이 단계의 PR):

- A.X 4.0 Light 는 구조가 qwen2 인데 어휘가 Qwen 의 것이 아니다(사전 처리 gpt-2 · 어휘 102,400). 비트 시험의 입력을 만드는
  [시험/입력7B.py](../시험/입력7B.py) 는 qwen2 면 Qwen 토크나이저를 써서 멈췄다 — Qwen 토크나이저가 받지 않는 qwen2 · qwen3 파일(사전 처리가
  qwen2 가 아닌 것)은 llama 구조처럼 llama-tokenize 로 토큰화한다.
- A.X 의 최대 문맥 길이는 16,384 다. 엔진은 문맥을 그 길이로 줄이는데 긴 문맥 시험은 n = 16,384 · 32,760 을 요청해 '범위 밖' 오류로
  끝났다 — 모델의 최대 문맥 길이가 32,768 보다 짧으면 문맥과 n 을 그 안으로 줄인다(넘는 n 은 문맥 − 8). 32,768 이상인 모델의 시험은
  그대로다.
- 모델 목록 항목 초안의 장치 문장이 0.12.0 12-4(공유 메모리 32 KB 장치의 k-양자화) 이전 문장이었다 — 헤드 128 의 k-양자화 파일은 모델
  목록의 설명과 같은 문장으로.

**못 미친 까닭(2026-11-09) — 고치려면 공유 코어(엔진 · 커널 생성기 · 서버)를 바꿔야 했다. 사용자 2026-11-10 "먼저 고쳐" → 아래 '고친 뒤'**:

- **Kanana 1.5 — CUDA 오류 716(misaligned address)**: 어휘가 128,259 개(홀수)다. 엔진의 k-양자화 가중치 배치([엔진/가중치K.gl](../엔진/가중치K.gl))는
  Q5_K · Q6_K 의 상위 비트를 [블록][열][4 · 8 바이트]로 두고, 커널은 그것을 16 바이트(`cp.async` 16)씩 — Q6_K 는 두 열, Q5_K 는 네 열 —
  복사한다. 열 수가 Q6_K 에서 홀수(Q5_K 에서 4 의 배수가 아님)면 홀수 번째 블록의 주소가 8 바이트 어긋난다. 층의 행렬은 열 수가 64 의
  배수라 출력 행렬 · 토큰 임베딩(열 수 = 어휘 수)만 걸린다 — Kanana 의 출력 행렬이 Q6_K 다. 어휘에 토큰을 더한 Llama 3 미세조정처럼 어휘
  수가 홀수인 파일은 모두 같다. 고치는 방법: 상위 비트의 열 간격(stride)을 4 의 배수로 올려 배치하고(엔진), 커널 생성기는 어휘 수가 4 의
  배수가 아닌 모듈에서만 그 간격으로 주소를 계산한다 — 지금 받는 모델의 모듈은 바이트까지 그대로다.
- **Kanana 1.5 — 채팅 템플릿**: 템플릿은 도구가 없을 때 `tools` 를 none 으로 두고 `tools | selectattr(…)` 를 부른다. jinja2 는 거짓인 값을
  빈 목록으로 돌려주지만(select · reject · selectattr · rejectattr · map), GeulPU 의 템플릿 해석기([엔진/진해석.gl](../엔진/진해석.gl))는
  '반복할 수 없는 값' 오류로 멈춘다 — 여덟 경우가 모두 이 오류다. 고치는 방법: 이 필터 다섯에서 거짓인 값을 빈 목록으로(jinja2 와 같게).
- **Kanana 1.5 — 도구 호출 형식**: 템플릿은 호출을 `<function=이름>{JSON}</function>`(functionary v3.1 — llama.cpp 의
  FUNCTIONARY_V3_1_LLAMA_3_1)으로 쓰라고 한다. GeulPU 는 이 형식을 아직 읽지 않는다(지금은 Llama 3 JSON 으로 고른다).
- **Mi:dm 2.0 — 도구 호출**: 템플릿은 호출을 Qwen 과 같은 `<tool_call>{JSON}</tool_call>` 로 쓰라고 하지만, Mi:dm 의 어휘에서 `<tool_call>` 은
  특수 토큰이 아니라 일반 텍스트다. 서버([엔진/채팅틀.gl](../엔진/채팅틀.gl))는 이 형식을 특수 토큰 ID 로 알아보므로 도구가 든 요청을
  오류로 돌려보낸다(채팅은 된다). 고치는 방법: 특수 토큰이 아닌 표시 문자열(`<tool_call>` · `<function=`)을 생성한 텍스트에서 알아보는 도구
  호출 형식 — llama.cpp 는 둘 다 읽는다(Hermes 2 Pro · functionary v3.1).
