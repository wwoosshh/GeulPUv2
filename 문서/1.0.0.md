# 1.0.0 — 성능 큰 폭 개선 · 빠른 모드의 기본을 8비트 KV + 빠른 어텐션으로 (계획 2026-10-22)

사용자 2026-10-22: "추천대로 진행하되 메이저버전을 올리려면 이번작업에 성능쪽개선을 큰폭으로 해서 이전과의 차이점을 보여줘야할것
같아". 0.10.2 뒤의 성능 추천 다섯(빠른 모드의 기본 · 프롬프트 행렬곱 효율 · 추측 검증 행 16 · 생성 스텝의 바닥 거리 · Qwen3 의 빠른
어텐션)을 1.0.0 하나로 묶는다. 기본 설정의 출력 비트가 바뀌므로 [버전 규칙](버전규칙.md)의 MAJOR 이고, 1.0.0 은 0.10.2 와의 차이를
같은 측정 묶음으로 보여 준다.
