## 소스에서 빌드하기

1. **준비물**: Windows(또는 Linux x86-64 — 아래 4), NVIDIA 드라이버(Ampere 이상) 또는 Vulkan 드라이버. 앱 · 서버는 이것과 글 컴파일러로
   충분하다. 시험은 Python 3.12 + `pip install -r requirements.txt`(numpy).
2. **글 컴파일러와 백엔드**: 글(geul) 저장소를 이 저장소 옆 `../geul-lang-v2` 에 받아 고정 판([시험/글저장소커밋.txt](../시험/글저장소커밋.txt)
   — 글 1.4.0 의 태그 `2g-1.4.0` 커밋. CI · 꾸리기 · 교차검증 기준이 모두 이 커밋이다)으로 맞추고 자체 호스팅 컴파일러를 만든다. PTX · SPIR-V
   백엔드는 이 저장소의 [백엔드/](../백엔드/)에 있고 그 컴파일러로 빌드한다(백엔드가 포함하는 앞단 `self/하강.gl` 은 `GEUL_ROOT` 의 글 저장소에서 온다).
   ```
   git clone https://github.com/wwoosshh/geul-lang ../geul-lang-v2
   cd ../geul-lang-v2
   git checkout $(tr -d '\r\n ' < ../GeulPUv2/시험/글저장소커밋.txt)
   python build.py selfhost 컴파일러
   cd ../GeulPUv2
   mkdir -p 빌드/글
   GEUL_ROOT=../geul-lang-v2 ../geul-lang-v2/build/self_컴파일러.exe 백엔드/PTX/PTX.gl -o 빌드/글/ptx-backend.exe
   GEUL_ROOT=../geul-lang-v2 ../geul-lang-v2/build/self_컴파일러.exe 백엔드/SPIRV/SPIRV.gl -o 빌드/글/spirv-backend.exe
   ```
3. **앱 꾸리기**(릴리스와 같은 것): `앱\꾸리기.ps1 -GeulRoot ..\geul-lang-v2 [-GeulC ..\geul-lang-v2\build\self_컴파일러.exe] -NoZip` 이
   `빌드\앱\GeulPU-<판>\` 에 `GeulPU.exe` · `bin\`(server-cuda · server-vulkan · device-cuda · device-vulkan · diag-cuda · diag-vulkan ·
   kernel-gen · ptx-backend · spirv-backend) · `kernels\` · `web\` · `data\` 를 만들고, 서버 · 생성기 · 백엔드의 SHA-256 을 교차검증 기준과
   비교한다. 모델의 커널 모듈은 앱이 처음 그 모델을 올릴 때 이 GPU 에 맞춰 만든다(데이터 폴더의 `모듈\<판>\`).

   **서버만 띄우기**: 생성기와 서버를 빌드하고, 모델의 모양 · 형식에 맞는 모듈을 만들어 PTX 로 바꿔 서버 옆에 두고 띄운다(모듈이 없으면
   서버가 만들 명령을 알린다). 터미널 실행기는 `엔진/실행기.gl`(`빌드/글/실행기.exe 모델.gguf` — 같은 모듈).
   ```
   mkdir -p 빌드/글
   GEUL_ROOT=../geul-lang-v2 ../geul-lang-v2/build/self_컴파일러.exe 커널/커널생성.gl -o 빌드/글/커널생성.exe
   GEUL_ROOT=../geul-lang-v2 ../geul-lang-v2/build/self_컴파일러.exe 엔진/서버.gl -o 빌드/글/서버.exe
   빌드/글/커널생성.exe qwen2큰 K 3584 28 4 18944 152064 빌드/글/qwen2K_3584x28x4x18944x152064.gl     # Qwen2.5-7B 의 k-양자화 모듈
   빌드/글/ptx-backend.exe 빌드/글/qwen2K_3584x28x4x18944x152064.gl -o 빌드/글/qwen2K_3584x28x4x18944x152064.ptx
   빌드/글/서버.exe 모델.gguf --슬롯 4 --문맥 4096 --포트 8080
   ```
4. **리눅스**: 같은 소스를 글 컴파일러의 리눅스 대상으로 빌드한다(ELF — 가져오는 것은 `libc.so.6` · `libcuda.so.1` 뿐). WSL2 Ubuntu 24.04
   에서 시험했고, 네이티브 리눅스에서 GPU 로는 아직 돌려 보지 않았다.

## 점검 — 커밋마다의 빠른 점검(CI)

[![빠른 점검](https://github.com/wwoosshh/GeulPUv2/actions/workflows/ci.yml/badge.svg)](https://github.com/wwoosshh/GeulPUv2/actions/workflows/ci.yml)

- **빠른 점검**(커밋마다, GPU · 모델 파일 없이 — GitHub Actions 의 Windows · Ubuntu 러너, 5 분 안팎, [시험/빠른점검.py](../시험/빠른점검.py)).
  글 컴파일러는 CPU 프로그램이라 커널 소스 → PTX · SPIR-V 까지는 GPU 없이 만든다: 글 저장소의 고정 판에서 글 컴파일러를 빌드하고,
  그것으로 백엔드 둘([백엔드/](../백엔드/)) · 생성기 · 엔진 프로그램 모두를 빌드하고, 모듈 스물둘(Qwen2 · Qwen3 · Llama 의 모양 · 형식 · 공유32 · 자리하나 · 빠른 계약)을 처음부터
  만들어 소스 · PTX · SPIR-V 를 [시험/모듈해시.txt](../시험/모듈해시.txt) 와 바이트까지 비교한다(커널이 뜻하지 않게 바뀌면 걸린다 — 일부러
  바꾼 커밋은 `--해시갱신`). NVIDIA ptxas(검사에만 — 엔진은 쓰지 않는다)로 SASS(sm_89)까지 만들어 커널마다 레지스터 · 넘침(spill)을
  적는다([시험/SASS넘침.txt](../시험/SASS넘침.txt)). 그 밖에 계약의 CPU 참조 자체 시험([시험/계약자체.py](../시험/계약자체.py)), 커널 변형 표가
  생성기 · 엔진에서 같은가, 실행기 · 서버 · 관리자의 가져오기 표(DLL), 파이썬 문법. 이 PC 에서도 같은 것을 돈다:
  `python -X utf8 시험/빠른점검.py --글 ../geul-lang-v2`.
- **GPU 시험**(손으로): 끝에서 끝의 비트 대조는 계약의 CPU 참조([시험/참조7B.py](../시험/참조7B.py)), 서버의 회귀 시험은
  [시험/서버28.py](../시험/서버28.py) · [시험/로그확률서버38.py](../시험/로그확률서버38.py). 연구 단계마다 돌린 공식 실행 스크립트는
  [GeulPU 의 공식실행/](https://github.com/wwoosshh/GeulPU/tree/main/공식실행)에 있다.
- **GPU 시험 · 재기에 드는 파일**(저장소에는 없다 — `모델/` · `빌드/` 는 git 이 무시한다):
  - 모델(GGUF): 시험과 재기는 GGUF 경로를 인자로 받는다. `재기/*.sh` 는 모델을 환경 변수 `GEULPU_MODELS` 의 폴더(기본 `F:/geulpu-models` —
    이 저장소를 만든 PC 의 것)에서, llama.cpp 를 `GEULPU_LLAMA_BENCH`(기본 그 아래의 `llama-b<판>`)에서 찾는다. 둘 다 ASCII 경로여야 한다
    (llama.cpp 도구가 한글 경로를 못 연다). `재기/MoE/전문가기록.py` 는 llama.cpp 의 DLL 폴더를 `GEULPU_LLAMA` 에서 찾는다.
  - 토크나이저: [시험/머리128.py](../시험/머리128.py) 의 층 0 채팅 질문은 시험에 주는 GGUF 안의 토크나이저를 쓴다 — 따로 받을 것이 없다.
  - wikitext-2: 품질 · 긴 문맥 재기(`시험/품질.py`, `재기/품질2b.sh` · `재기/추측3.py` 등)는 `빌드/wikitext-2/wiki.test.raw` 를 읽는다. llama.cpp 의
    퍼플렉시티 측정과 같은 파일이다 — llama.cpp 저장소의 `scripts/get-wikitext-2.sh` 가 받는 `wikitext-2-raw-v1.zip` 의
    `wikitext-2-raw/wiki.test.raw` 를 그 자리에 둔다(sha256 `173c87a53759e020…`).
