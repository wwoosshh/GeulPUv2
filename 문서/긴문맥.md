## ③a 위치 늘이기 — 자세히(이번 승인 대상)

### 어떻게

- **YaRN**(Qwen2.5 · Qwen3 의 모델 카드 · config 의 `rope_scaling: {type: yarn, factor: 4, original_max_position_embeddings: 32768}` —
  transformers · vLLM · llama.cpp 의 같은 식):
  - 주파수: 짝 i 마다 θ_i = base^(−2i/d). 원래 문맥에서 도는 바퀴 수로 정한 두 경계(β_fast 32 · β_slow 1 — low · high 짝)
    사이를 곧은 경사 r_i 로 섞어 θ′_i = θ_i · ((1 − r_i)/s + r_i) — 높은 주파수는 그대로, 낮은 주파수는 1/s. 이것은 계약 4.7 (2)의
    θ′_i = θ_i / f_i 꼴(f_i = 1 / ((1 − r_i)/s + r_i))이라 **이미 있는 Llama 3.1 의 길에 인자만 더한다**.
  - 크기: cos · sin 에 mscale = 0.1 · ln(s) + 1 을 곱한다(q · k 둘 다 — 어텐션 온도). 표의 값이 바뀔 뿐 커널은 그대로.
  - **계약 4.7 (2′)**: f_i 와 mscale 의 셈(fp64 — 경계는 transformers 의 find_correction_range 와 같은 floor · ceil), 표 값 =
    짧은실수(mscale × cos(위치 · θ′_i))를 바르게(두 배 정밀도 — 지금 표와 같은 길). CPU 참조(계약/정수계약.py)가 같은 식.
- **켜는 때**: 설정의 문맥이 모델의 원래 길이(32,768)를 넘을 때만 s = 4(Qwen 공식 — 짧은 글에서 조금 손해가 있어 원래 길이 안에서는
  끈다, vLLM · llama.cpp 의 정적 YaRN 과 같은 판단). Qwen2.5 · Qwen2.5-Coder · Qwen3 만(모델 이름이 아니라 구조 qwen2 · qwen3 이고
  GGUF 에 rope 늘이기가 없을 때). 그 밖은 그대로.
- **앱**: 모델 화면의 "문맥 최대"를 YaRN 을 켤 수 있는 모델은 131,072 로 보이고, 켜진 때를 모델 불러오기 기록에 남긴다("YaRN — 32,768
  → 131,072").

### 맞음(미리 정함)

1. **계약**: RoPE 표(위치 0 ~ 131,071)가 엔진 · CPU 참조에서 비트까지 같다. 머리128 의 긴 경우 · 엔진/시험_긴문맥을 65,536 · 98,304 ·
   131,072 근처까지(프롬프트 길 · 표 걸음 행 1 · 행 8 · 그래프가 같은 비트, CPU 참조와 같음).
2. **식이 맞는가** — llama.cpp 최신(b11724, `--rope-scaling yarn --rope-scale 4 --yarn-orig-ctx 32768`)과 같은 64k 글의 다음 토큰
   분포를 견준다(엔진이 달라 비트는 아니고 KL · 첫째 일치 — 지금 32k 안의 차이와 같은 급이면 맞다).
3. **바늘 찾기**: 긴 글(재기 입력의 긴 글을 되풀이) 속 깊이 10 · 50 · 90 % 에 숨긴 문장("비밀 번호는 7429")을 32k · 64k · 96k 문맥에서
   묻는다 — Qwen2.5-7B · Coder-7B, llama.cpp 와 맞은 수를 견준다.
4. **이 PC 의 최대 문맥** 표를 다시(Qwen2.5-7B · Coder-7B · Qwen3-8B), 그 문맥에서 코딩 에이전트(Qwen Code) 일 하나.
5. **그대로인 것**: 원래 길이 안(32,768 이하)은 바이트까지 그대로 — 교차검증 R1 32/32 · 모듈 해시 · 빠른점검. 커널 · 모듈은 바뀌지 않는다.
6. 속도(참고): 64k · 96k 의 빈 프롬프트 · 깊이마다 생성 — ③c 의 출발점으로 적는다(이 단계의 목표는 아님).

### 받을 것(승인 필요)

- **llama.cpp 최신**(github.com/ggml-org/llama.cpp 공식 릴리스 — 2026-10-20 에 b11744, `llama-b11744-bin-win-cuda-13.4-x64.zip` 약 155 MB) — 위 2 · 3 의 견줌.
  cudart(13.4)는 F: 보관본(b11669 때 받은 것 — 크기 423,535,356 바이트, 지금 릴리스의 것과 같은 크기)을 E: 로 복사해 쓴다(해시를 견줌).
- 받은 것 · 시험 모델 복사본은 E:(SSD)에, 끝나면 지운다.

### 위험

- YaRN 은 모델이 늘인 위치를 '배운' 것이 아니라 끼워 맞추는 것 — 긴 글의 질은 모델의 몫(바늘 찾기로 잰다). Qwen 이 공식으로 권하는 값이라
  다른 엔진과 같은 질이어야 한다.
- 원래 길이를 넘는 문맥을 켜면 그 채팅의 짧은 글도 YaRN 으로 셈한다(정적 YaRN — 다른 엔진과 같음) — 문서에 적는다.
- 131,072 는 엔진의 묶음 한도와 같아 ③a 안에서는 넘지 않는다(③d).
