# 버전 규칙

**[English](../docs/versioning.md)** · [README](../README.ko.md) · [바뀐 것](바뀐것.md)

GeulPU 의 버전은 `MAJOR.MINOR.PATCH`(예: `0.7.0`)다. 버전은 [`앱/판.gl`](../앱/판.gl) 한 곳에 적고, 릴리스 태그는 `v` + 그 번호다(둘이
다르면 릴리스 워크플로가 멈춘다). 앱 · 릴리스 zip · PyPI 패키지 `geulpu` 는 늘 같은 번호다.

| 자리 | 올리는 때 | 예 |
|---|---|---|
| **MAJOR**(첫째) | 이전 버전과 **호환되지 않는** 업데이트 | 문서에 적힌 API 필드를 뺌 · 이전 버전이 쓴 실행 로그를 못 읽음 · 같은 요청의 출력 비트가 달라짐 |
| **MINOR**(가운데) | **기능 추가** — 이전에 되던 것은 모두 그대로 | 디버거(0.7.0) · 프롬프트 캐시(0.6.0) · 새 모델 계열 · 새 API 필드 · 출력 비트가 같은 더 빠른 커널 |
| **PATCH**(마지막) | **버그 수정 · 작은 수정** | 충돌 고침 · 틀린 결과 고침 · 화면 문구 · 문서 고침 |

한 자리를 올리면 그 오른쪽 자리는 0 으로 돌아간다: 0.7.0 → 0.7.1 → 0.8.0 → 1.0.0. 이 규칙은 0.7.0 부터다. 첫째 자리가 0 이어도 예외가
아니다 — 0.7.0 뒤 처음으로 호환되지 않는 업데이트가 나오면 다음 버전은 1.0.0 이다.

## 호환의 범위

GeulPU 는 사람뿐 아니라 프로그램도 쓰고, 약속하는 것이 재현성이라 호환은 네 가지를 뜻한다.

1. **인터페이스**: HTTP API — OpenAI 호환 엔드포인트(`/v1/chat/completions` · `/v1/completions` · `/v1/models`), `/tokenize` ·
   `/detokenize` · `/tokenizer_info`, 디버거 API(`/api/debug/…`), 추론 서버의 프롬프트 캐시 API(`/geulpu/store`) — 와 요청 · 응답의
   `geulpu` 확장 필드, `GeulPU.exe` · `geulpu` 의 명령줄 옵션, [`도구/`](../도구/)의 도구(`debugger.py` · `repro_check.py`)의 명령 ·
   옵션. 이것을 빼거나 이름을 바꾸거나 뜻을 바꾸면 호환되지 않는다. 엔드포인트 · 필드 · 옵션 · 명령을 더하는 것은 호환된다. 앱의 화면만
   쓰는 내부 엔드포인트는 범위 밖이다.
2. **파일**: 실행 로그(`"format": "geulpu-run-log/1"`) · 재현 파일 · 데이터 폴더의 설정과 모델 목록. 이전 버전이 쓴 파일은 모두 읽어야
   한다. 형식을 바꾸면 형식 버전을 올리고(`geulpu-run-log/2`), 옛 형식을 못 읽게 되면 호환되지 않는다. 캐시 — 커널 모듈 · 프롬프트
   캐시 · 튜닝 캐시 — 는 필요할 때 다시 만들어지므로 범위 밖이다.
3. **출력 비트**: 같은 모델 파일 · 계산 방식 · YaRN 배율 · 요청(시드 포함)이면 토큰 · 로그확률 · 로짓 해시가 버전이 바뀌어도 같다 —
   이전 버전에서 기록한 실행 로그가 비트까지 재생된다. 이것이 바뀌면 호환되지 않는다. 다만 [정밀도 계약](../계약/계약.md)의 CPU 참조와
   맞지 않던 결과를 고친 것은 PATCH 이고, 바뀐 것 기록에 **출력 바뀜**(Output change)으로 적는다. 새 계산 방식을 더하는 것은 MINOR 다.
4. **지원**: 이전 버전이 돌리던 모델 계열 · 가중치 형식 · GPU · 운영체제. 하나라도 빼면 호환되지 않는다.

속도 · 메모리 사용량 · 화면 모양 · 메시지 문구는 범위 밖이다(바뀌면 바뀐 것 기록에는 적는다).

## 지원 중단 예고(deprecation)

MAJOR 에서 무엇을 빼기 전에, 그 앞의 MINOR 에서 바뀐 것 기록에 지원 중단 예고를 적고 계속 받아 준다 — 도구들이 옛 옵션 이름을 아직
받는 것처럼.

(영어), 버전마다 바뀐 것은 [바뀐것.md](바뀐것.md)와 [CHANGELOG.md](../CHANGELOG.md)(영어).
