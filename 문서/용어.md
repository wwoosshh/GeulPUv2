# 용어

GeulPU 의 문서 · 화면 · 도구 · 보고에 쓰는 용어(사용자 2026-10-20). 연구자가 이미 아는 말을 쓴다.

## 원칙

1. 한국어 문장에는 이미 쓰이는 IT · 머신러닝 용어를 쓰고, 문서에서 처음 나올 때 영어를 함께 적는다 — 예: 중단점(breakpoint).
2. CLI 의 명령 · 옵션, API 의 경로 · 필드, 파일 형식의 키(key)는 영어로 쓴다. 이미 있는 표준(OpenAI · vLLM · llama.cpp)의 이름이 있으면
   그것을 따른다.
3. 새 말을 만들지 않는다. 표준 이름이 없는 것은 풀어 쓴다.
4. 글(geul) 코드의 식별자는 언어 설계상 한국어다 — 코드 안의 이름은 이 표와 다를 수 있다(예: `메아리셈` = echo 스코어링의 계산,
   `걸음` = 스텝). 코드를 읽을 때의 뜻은 [docs/glossary.md](../docs/glossary.md).

에뮬레이션(emulation) · 자리(digit — 정밀도 계약의 균형 256진 자리. 문장에서는 '16비트 형식(8비트 자리 둘)'처럼 비트 수와 함께 쓴다).

새로 만드는 스크립트 · 도구의 명령과 옵션은 영어로 짓는다(원칙 2 — 예: `재기/캐시축출.py --check`, `재기/KV행동.py ask · compare`). 커밋하기
전에 새로 쓴 문장을 이 표의 왼쪽 열로 훑는다.

지난 단계 기록(문서/2단계 … 4b단계)에는 코드의 이름을 그대로 옮긴 말(예: 판 = 커널 변형 · 공유 메모리 배열의 이름, `표걸음` ·
`큰조각셈`)이 남아 있다. 코드를 읽을 때의 뜻은 [docs/glossary.md](../docs/glossary.md).
