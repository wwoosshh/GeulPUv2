# 층 렌즈 — logit lens (#96)

연구 패널은 지금 끝의 다음 토큰 분포(확률 · 순위 · 상위 10 · 엔트로피 · 마진)만 보인다. 층 렌즈는 고른 걸음에서 그 토큰을 매긴 행의
residual stream 을 층마다 끝의 로짓 계산(끝 RMSNorm + 출력 헤드)으로 읽어, 모델이 그 층에서 멈췄다면 낼 분포를 보인다(logit lens —
nostalgebraist 2020). 답이 몇 번째 층에서 생기는지, 되풀이 · 다른 언어로 넘어가기 같은 실패가 어느 층에서 시작되는지, 양자화 둘이
어느 층부터 갈라지는지를 본다. 계산은 [계약 5.3](../계약/계약.md) — 끝 로짓과 같은
식을 중간 층에 쓰는 것이라 GPU 마다 · 실행마다 비트까지 같고, CPU 참조가 GPU 없이 다시 셈한다.

## 2단계 — Jacobian lens

Anthropic 의 Jacobian lens([anthropics/jacobian-lens](https://github.com/anthropics/jacobian-lens), 2026)는 층 l 의 residual 을 끝 층의 바탕으로
옮긴 뒤 읽는다 — lens_l(h) = unembed(J_l h). J_l 은 원본 모델에서 프롬프트의 자리 p 마다 Σ_{p′ ≥ p} ∂x_{L−1}(p′)/∂x_l(p) 를 평균한 것으로,
jlens 가 역전파로 맞춘다. logit lens 는 가운데 층의 residual 을 끝 층의 것처럼 읽으므로 앞 층일수록 흐린데, J_l 이 그 바탕의 차이를
옮겨 준다. GeulPU 는 GGUF(양자화 파일)를 돌리고 역전파가 없으므로 J 는 원본(Hugging Face BF16)에서 맞춘다 — 그래서 먼저 원본에서 맞춘
J 가 GGUF 파일에 옮겨 가는지를 미리 정한 기준으로 쟀다(2c).

## PR ④ — 엔진 · 서버 · 연구 패널

- **API**: 5.3 의 echo 요청에 `geulpu.layer_lens: {"jacobian": true}`(`top_k` 와 함께 쓸 수 있다) — 응답 `geulpu.jacobian_lens` 는
  `layer_lens` 와 같은 꼴에 `jlens_sha256`(J 파일의 SHA-256) · `source_layers`(원천 층 수)를 더한다. 서버는 `--jlens <J 파일>` 로 띄워야
  하고(아니면 400), 시작할 때 J 파일의 꼴을 보고 기록에 "Jacobian lens: J 파일 … · SHA-256 …" 또는 받지 않은 까닭을 적는다.
- **엔진**([엔진/엔진.gl](../엔진/엔진.gl)): `J렌즈계획짓기(m)` — `잔차켬` 이면 `층렌즈띄움` 이 읽는 대신 계획을 층마다 맺는다(조각 L + 1 개 —
  조각 l 은 층 l 까지, 마지막 조각은 끝 정규화 · 출력 헤드). `J렌즈계산(m, 위치시작, 잔차)` 이 조각을 차례로 띄우며 조각마다 행 0 의 잔차
  (버h — x_l)를 내린다. `J렌즈읽기(R, 행들)` 은 호스트의 행 R 개를 끝 로짓과 같은 두 판(출력 정규화 RMS · 출력 헤드)으로 읽어 `렌즈칸2` 에.
  커널은 바꾸지 않았다 — 모듈 해시 그대로.
- **호스트**([엔진/J렌즈.gl](../엔진/J렌즈.gl)): J 파일 열기(safetensors 머리 JSON, F16 [D][D], 빈틈 없는 자료, 무한 · NaN 인 반실수 거절,
  SHA-256)와 `J곱들` — 계약 5.4 의 2(배정밀도의 차례 합, 반실수 → 배정밀도 표, 규칙 R 의 입력 · 끝). 칸(층 · 행)을 일꾼 스레드로 나눈다 —
  칸끼리 따로라 나눔과 상관없이 같은 비트(한 스레드 판과 견줘 같음).
- **서버**([엔진/서버몸.gl](../엔진/서버몸.gl)): 첫 echo 덩이에서 `J렌즈계산` → x_l → 층 0 … L − 2 의 `J곱` → 행 2L(x_0 … x_{L−1}, u_0 … u_{L−2},
  x_{L−1})을 `J렌즈읽기` 로 한 번에 → 두 렌즈의 층마다 5.2(`층마다셈`). 이 길의 `layer_lens` 는 J 를 묻지 않은 응답과 비트까지 같다(행끼리 따로).
- **앱**: 모델 파일 옆에 `<이름>.jlens.safetensors` 가 있으면 서버에 `--jlens` 로 넘기고, 서버의 기록에서 결과를 읽어 상태에(`server.jlens_sha256`
  · `jlens_file` · `jlens_reason`). 연구 패널의 '층 렌즈'는 서버가 J 파일을 열었으면 같은 요청으로 두 렌즈를 읽고 'logit lens | Jacobian lens'
  로 바꿔 보인다. 재현 파일에 셈한 Jacobian lens(`result.jacobian_lens`)와 J 파일(`jlens.sha256`)이 들어가고, `repro_check --jlens` 가 같은
  J 파일일 때 그 값을 비트까지 견준다.
- **검증**(2026-10-25 — Qwen3-0.6B Q8_0 과 옆의 J 파일(2b)): [시험/렌즈.py](../시험/렌즈.py) `--jlens` — 정밀 CUDA · 정밀 Vulkan · 빠른(F1)
